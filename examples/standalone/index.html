CollabHTML / a collaboration layer over HTML

Make any HTML collaborative.

A document can be more than a final answer. It can be a place to ask questions, check evidence, and improve an idea together.

Try it: enter your name in the Comments pane. Select a sentence here, then add a comment. Reply, resolve, and save an HTML copy with comments. Open that copy offline: your comments travel with it.

Three parts, two ways to use them

The CollabHTML primitive owns the comment data and the text anchors. It has no screen of its own. An optional default UI draws the Comments pane you see here, and you can replace it with your own. The host owns identity, permissions, encryption, and shared storage.

Standalone: the saved file carries the comments, so no server is needed. Hosted: a viewer service stores them. Both use the same comment format.
